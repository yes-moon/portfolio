## 2. JDK 17 설치 (Eclipse Temurin, 무료 LTS)
1. 다운로드: https://adoptium.net/temurin/releases/ → **Version 17 (LTS), Windows, x64, JDK, .msi** 선택.
2. 설치: 설치 마법사에서 **"Set JAVA_HOME variable"** 와 **"Add to PATH"** 옵션을 반드시 체크.
3. 확인 (PowerShell 새 창):
   ```powershell
   java -version      # 17.x 나오면 정상
   javac -version     # 17.x (컴파일러 존재 확인)
   $env:JAVA_HOME     # C:\Program Files\Eclipse Adoptium\jdk-17... 표시
   ```
4. ⚠️ 만약 `java -version` 이 여전히 옛 1.8 로 나오면: 구형 32비트 JRE(`C:\Program Files (x86)\...\javapath`)가 PATH 앞에 있는 것. 시스템 환경변수 Path에서 **`%JAVA_HOME%\bin` 을 맨 위로** 올리고 새 터미널에서 재확인.

## 3. Oracle Database 23ai Free 설치 (네이티브, 무료)
> Docker 안 씀(WSL2 미설치). 네이티브 설치가 이 PC엔 더 단순.
1. 다운로드: https://www.oracle.com/database/free/ → **Oracle Database 23ai Free — Windows x64** (ZIP 또는 설치본).
2. 압축 해제 후 **setup.exe** 실행 → 관리자 계정(SYS/SYSTEM) **비밀번호 설정**(예: `UnivA#2026` — 메모해둘 것).
3. 설치 완료 시 기본값:
   - 서비스명: `OracleServiceFREE`  / 리스너: `OracleOraDB23Free...TNSListener`
   - 접속 대상(PDB): `FREEPDB1` / 포트 1521
   - `sqlplus` 는 `%ORACLE_HOME%\bin` 에 자동 설치됨.
4. **★메모리 절약 설정(구형 CPU 배려)** — 부팅 시 자동 구동 끄고, 쓸 때만 켜기:
   ```powershell
   # 관리자 PowerShell에서 (자동시작 → 수동으로)
   Set-Service -Name OracleServiceFREE -StartupType Manual
   # 개발 시작할 때 켜기 / 끝나면 끄기
   Start-Service OracleServiceFREE      # 켜기
   # Stop-Service OracleServiceFREE     # 끄기(메모리 회수)
   ```

## 4. DB 계정·스키마 생성 (우리 앱 전용 공간)
1. 관리자 접속:
   ```powershell
   sqlplus sys/UnivA#2026@localhost:1521/FREEPDB1 as sysdba
   ```
2. 앱 전용 사용자(스키마) 생성 — SQL*Plus 프롬프트에서:
   ```sql
   CREATE USER univa_survey IDENTIFIED BY '***REDACTED***';
   GRANT CONNECT, RESOURCE TO univa_survey;
   ALTER USER univa_survey QUOTA UNLIMITED ON USERS;
   EXIT;
   ```
   > 여기서 만든 `univa_survey` 가 설계_01 0-5의 "스키마=옆집 창고 한 칸"에 해당. 실제 학교에선 학교 Oracle에 이 스키마만 추가하면 됨(라이선스 0원 시나리오).

## 5. SQL Developer 설치 (무료 GUI, 설치 아닌 압축해제)
1. 다운로드: https://www.oracle.com/database/sqldeveloper/ → Windows 64-bit (JDK 포함본 권장).
2. 압축 해제 후 `sqldeveloper.exe` 실행.
3. 새 접속 만들기: 사용자 `univa_survey` / 비번 `survey2026` / 호스트 `localhost` / 포트 `1521` / 서비스명 `FREEPDB1` → **테스트 → 접속**.

## ★6. 검증 마일스톤 — 우리가 만든 걸 실제로 돌려보기
> 이 단계가 이번 목표. 그동안 만든 스키마·검증SQL을 실행해 눈으로 확인.
1. SQL Developer에서 `univa_survey` 로 접속한 워크시트를 연다.
2. **스키마 생성**: `d:\2026_[A대학교]_통합조사 플랫폼구축\설계_06_ddl_oracle_se2.sql` 열기 → 전체 실행(F5).
   - 기대: 시퀀스 32개 + 테이블 42개 + FK + 인덱스가 오류 없이 생성. (경고 없이 완주하면 성공)
   - 확인 쿼리:
     ```sql
     SELECT COUNT(*) FROM user_tables;   -- 42 나와야 정상
     SELECT COUNT(*) FROM user_sequences; -- 32
     ```
3. **분석능력 증명**: `설계_07_검증_샘플데이터_쿼리.sql` 열기 → 전체 실행.
   - 기대: [V1] Q1평균 3.75 / [V2] 컴공 4.00·경영 3.33 / [V3] 컴공2학년만 노출·나머지 억제 / [V4] 교수법 4.67 / [V6] 중복토큰 거부 메시지 / [V8] 교무처 과제 1건. (각 결과를 스크립트 주석의 기대값과 대조)
   - **여기서 기대값과 실제가 일치하면**: 우리가 설계·검증한 스키마가 실제 Oracle에서 RFP 분석요구를 답한다는 것이 증명됨. ← 이번 단계 성공 기준.

## 7. eGovFrame 개발환경 설치 (Eclipse 기반, 무료)
> RFP 정성평가 "표준 프레임워크 적용" 대응. eGovFrame이 제공하는 올인원 개발환경 사용.
1. 다운로드: https://www.egovframe.go.kr/ → 개발환경(구현도구) 최신(4.x) Windows 64bit.
   - eGovFrame 4.x는 JDK 17 호환. (2번에서 설치한 JDK 17 사용)
2. 압축 해제(설치 아님) → `eclipse.exe`(또는 devInstall) 실행.
3. 첫 실행 시 워크스페이스 지정: 예 `D:\dev\workspace-univa`.
4. JDK 지정: Window→Preferences→Java→Installed JREs 에서 **JDK 17** 추가·선택.
5. (다음 세션에서) eGovFrame 프로젝트 생성 → 설계_05 골격대로 패키지 구성 → Oracle 연결(위 univa_survey) → 로그인·설문 최소기능 순으로 개발.

## 부록 A. 메모리 관리 습관 (16GB, 구형 CPU 배려)
- Oracle은 안 쓸 때 `Stop-Service OracleServiceFREE` 로 끄면 ~2GB 회수.
- 빌드(Maven)할 때 무거운 브라우저 탭·앱을 잠깐 닫으면 쾌적.
- 동시 실행 피크(IDE+Oracle+Tomcat+브라우저) ~7GB → 16GB로 여유 있음.

## 부록 B. 자주 나는 문제
- **`java`가 옛 1.8로 나옴** → 2-4번(PATH 정리) 참고.
- **Oracle 접속 안 됨(ORA-12541 등)** → 서비스·리스너 켜졌는지: `Get-Service Oracle*`, 안 켜졌으면 `Start-Service`.
- **한글 깨짐** → DB 캐릭터셋 확인: `SELECT value FROM nls_database_parameters WHERE parameter='NLS_CHARACTERSET';` → `AL32UTF8` 확인(설계_06 전제).
- **DDL 재실행 시 "이미 존재" 오류** → 새로 하려면 스키마 비우기: SQL Developer에서 univa_survey 접속 후 모든 객체 드롭, 또는 사용자 재생성(4번).
