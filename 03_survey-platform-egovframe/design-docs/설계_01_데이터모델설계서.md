## 0. 설계 원칙 (★심사·품질평가 대응 근거)

### 0-1. DBMS 전제 및 Oracle SE2 제약 반영 (DAR-001, PER-001)
- **대상 DBMS: Oracle Database SE2** (RFP 지정). **개발용은 Oracle Database Free(23ai)** — SQL 문법 호환, 무료, 원격지 개발 방침과 정합.
- **SE2 제약 → 설계 대응**:
  - SE2는 **테이블 파티셔닝 미지원** → 대용량 응답 테이블은 **연도(YEAR) 컬럼 + 복합 인덱스**로 파티셔닝을 대체. 조회는 항상 연도 조건을 선두에 둔다.
  - SE2는 **병렬쿼리(Parallel Query) 미지원** → 대량 집계는 실시간 쿼리 대신 **집계 스냅샷 테이블(SV_STAT_SUMMARY)** 을 배치로 산출해 대시보드·보고서 응답속도(PER-002: 3초 이내) 보장.
  - SE2 소켓 2개 제한 → 서버 사양 확인 시 코어·소켓 수 필수(서버사양 미확정 항목).
- **캐릭터셋: AL32UTF8** (DAR-001). ★주의: AL32UTF8은 여러 언어 '문자 저장'일 뿐 i18n(문항·보기를 언어별로 제공)이 아니다. 다국어 '데이터 지원' 요구 대비로 문항·보기·조사명에 **LANG_CD 기반 다국어 골격**을 마련(QB_QUESTION_LANG 등 확장 슬롯). 실제 다국어 제공 범위(예: 외국인 유학생 대상 영/중 병기 여부)는 **발주처 협의로 확정**(미확정 항목).
- **Temporary Tablespace 분리** (DAR-001): 실시간용/대용량 배치용 임시 테이블스페이스 분리 운영(운영 설치 시 DBA 협의).

### 0-2. 명명 규칙 (SFR "기타": [A대학교] 운영시스템 Naming Rule 준수 — 미확정, 아래는 잠정안)
- 테이블: `모듈접두어_업무명` (대문자, 스네이크). 접두어: `CM`(공통/기준), `SV`(조사), `QB`(문항은행), `FB`(환류), `RP`(보고서).
- PK: `업무명_ID` (예: SURVEY_ID). 대리키(시퀀스/IDENTITY) 사용.
- 컬럼: 대문자 스네이크. 코드 컬럼은 `_CD`, 여부는 `_YN`, 일시는 `_DT`, 일자는 `_YMD`, 명칭은 `_NM`.
- **주의**: 확정된 학교 Naming Rule 입수 시 일괄 리네이밍(설계 단계에서만 반영 가능하므로 초기 확정 중요).

### 0-4. 보안·개인정보 설계 (SER-001·002, COR-001, 용역수행지침 5-가)
- 주민등록번호 **미수집**(RFP 수집제한 정책). 개인식별은 학번/사번/외부계정ID.
- 개인정보(이름·연락처·이메일) 컬럼은 **암호화 대상**으로 표시(운영 시 암호화 컬럼 적용). 아래 정의서에 `[암]` 표기.
- 접근권한은 역할기반(RBAC): CM_ROLE / CM_ROLE_MENU. 부서담당자는 본인 부서 환류과제만 조회(라. 요구 — FB 테이블 부서 조건).
- 중요 DB 접근·변경 이력 관리(COR-001) → CM_LOG_* 3종(접속/기능/다운로드).

### 0-5. 비식별 응답 + 소집단 억제 설계 (★검증 반영 — SFR-006 중복방지 ↔ SFR-008 분석 ↔ SER-002 개인정보)
> ⚠️ 용어 교정: "구조적 익명"은 성립하지 않는다(시각 근접·소집단 재식별 가능). 정확히는 **"비식별(pseudonymize) + 재식별 방지 + 소집단 억제"** 로 기술한다. 제안서도 이 표현 사용(심사 역공 차단).
- **문제**: 만족도조사는 대개 익명. SFR-008은 부서·학과·학년별 분석 요구. 단순 2-트랙 분리만으로는 ①응답일시 근접(RESP_DT≈SUBMIT_DT)+소속 일치로 재식별 ②소규모 학과·학년(응답 1~2명) 집계·주관식 열람 시 개인 특정 위험.
- **해법(4중 방어)**:
  1. **응답여부 추적(중복방지)**: `SV_RESPONDENT.RESP_YN`/`RESP_YMD`(일자 단위)에만 표시. 응답 "내용"(SV_RESPONSE/ANSWER)과 조인하지 않는다. 응답여부 갱신과 내용저장은 **분리 트랜잭션**으로 시각 상관을 끊는다.
  2. **비식별 내용 저장**: 익명 조사 시 `SV_RESPONSE.RESPONDENT_ID=NULL`. 소속은 **스냅샷(대상유형·부서·학과·학년)** 만 저장. `SUBMIT_DT`도 익명 조사에서는 일자 단위(또는 시간대 버킷)로 저장해 시각 재식별 차단.
  3. **소집단 억제(suppression)**: `SV_STAT_SUMMARY.RESP_CNT < N(기본 5, 설정)` 셀은 집계·화면·다운로드에서 마스킹. 주관식 원문도 소집단에서는 부서담당자에게 미노출. `MASK_YN` 컬럼으로 관리.
  4. **기명(NAMED) 조사**: `RESPONDENT_ID` 저장(추적 허용), 개인정보 규정 준수·접근권한 차등(COR-001).
- 개인정보보호(COR-001·SER-002·용역지침 5-가)와 분석요구(SFR-008)를 동시 충족하는 근거로 제안서 명시. 임계값 N은 발주처 협의.

## 1. 도메인 구성 (텍스트 ERD 개요)

```
[기준정보/공통 CM]  사용자(보직)·부서·학과·권한·메뉴·공통코드·로그3종·공지/자료실·알림
        │ (조사 담당부서/담당자, 대상자 소속)
        ▼
[조사관리 SV_SURVEY] ──< [조사대상유형 SV_SURVEY_TARGET] (다중대상 정규화)
        │
        ├──< [조사문항 SV_SURVEY_QUESTION] >── [문항은행 QB_QUESTION] ─┬[보기 QB_QUESTION_OPT]
        │            │  ├(보기스냅샷 SV_SQ_OPT)                          ├[행렬행 QB_QUESTION_ROW]
        │            │  └(행렬행 스냅샷 SV_SQ_ROW)                        └[척도 QB_SCALE]
        │     [템플릿 SV_TEMPLATE]──<[템플릿문항 SV_TEMPLATE_QUESTION]
        ├──< [조사대상자 SV_RESPONDENT] ──< [발송이력 SV_SEND_HIST]
        ├──< [배포 SV_DISTRIBUTION]
        ├──< [응답 SV_RESPONSE(비식별 소속스냅샷)] ──< [응답상세 SV_ANSWER(행렬 ROW_ID)]
        ├──> [집계스냅샷 SV_STAT_SUMMARY(2차원 교차+억제)]
        └──> [보고서 RP_REPORT]
        │
        ▼ (조사결과 확정 → 환류)
[환류 FB] 문항-부서매핑 FB_Q_DEPT_MAP → 개선과제 FB_TASK → 개선계획 FB_PLAN
                                              → 실행결과 FB_RESULT → 증빙 FB_EVIDENCE
                                              → 연도연계 FB_TASK_LINK (전년 대비 이행점검)
[공통파일 CM_FILE] ← 증빙·보고서·첨부 참조
```

| COPY_FROM_ID | NUMBER | | 복사 원본 조사(반복조사 SFR-003) |

### 3-4. QB_QUESTION (문항은행) / QB_QUESTION_OPT (보기) / QB_SCALE (척도)
- QB_QUESTION: QUESTION_ID(PK), QUESTION_TX(문항내용), QTYPE_CD(★단일선택/복수선택/척도형/행렬형/단답형/서술형/만족도형 — 7유형), QB_CATE_CD(공통문항/선택문항/부서특화문항), OWNER_DEPT_ID(부서특화 시), SCALE_ID(FK, 척도형·행렬형 공유척도), REQUIRED_DEF_YN(기본필수), USE_CNT(사용횟수 — 중복성/사용이력 SFR-004)
- QB_QUESTION_OPT: OPT_ID(PK), QUESTION_ID(FK), OPT_TX(보기내용=열), OPT_SEQ(순서), OPT_SCORE(점수/척도값), ETC_INPUT_YN(기타 의견 입력)
- **QB_QUESTION_ROW**(★행렬형 행 — 검증 반영): ROW_ID(PK), QUESTION_ID(FK), ROW_TX(하위 항목명 예: 강의내용/교수법/과제물), ROW_SEQ(순서). 행렬형은 이 '행' × QB_QUESTION_OPT의 '열(척도)' 교차로 구성.
- QB_SCALE: SCALE_ID(PK), SCALE_NM(예: 5점 리커트), SCALE_POINT(5/7), MIN_LABEL/MAX_LABEL(양극 라벨)
- QB_QUESTION_HIST: 변경이력(SFR-004 변경이력 요구) — QUESTION_ID, VER_NO, CHG_TX, REG_DT

### 3-5. SV_SURVEY_QUESTION (조사편성 문항) / SV_SQ_OPT (보기 스냅샷) / SV_SQ_ROW (행 스냅샷)
- SV_SURVEY_QUESTION: SQ_ID(PK), SURVEY_ID(FK), QUESTION_ID(FK, 은행참조), Q_SEQ(순서변경 SFR-003), REQUIRED_YN(필수응답 설정), SECTION_ID(FK, 영역 코드 — ★자유텍스트 SECTION_NM 대신 정규화, 문항-부서 매핑 안정), QUESTION_TX_SNAP(편성시점 문항문구 스냅샷)
  - **설계 포인트**: 문항은행 원본이 나중에 수정돼도 과거 조사 결과가 흔들리지 않도록, 편성 시점의 문항문구·보기·행을 **스냅샷**으로 보존.
  - **영역(SECTION)**: 공통코드/기준테이블로 관리(SECTION_ID)하여 오타·개명에 의한 환류 자동분류 실패 차단(검증 중요-2 반영).
- SV_SQ_OPT: SQ_OPT_ID(PK), SQ_ID(FK), OPT_TX, OPT_SEQ, OPT_SCORE, ETC_INPUT_YN
- **SV_SQ_ROW**(★행렬형 행 스냅샷): SQ_ROW_ID(PK), SQ_ID(FK), ROW_TX, ROW_SEQ — 응답 저장 시 SV_ANSWER가 이 행을 참조.

### 3-6. SV_RESPONDENT (조사대상자) / SV_SEND_HIST (발송이력)
- SV_RESPONDENT: RESPONDENT_ID(PK), SURVEY_ID(FK), USER_ID(FK, 학내대상자) 또는 EXT_KEY(외부), TARGET_TYPE_CD, DEPT_ID/MAJOR_ID(분석단위 스냅샷), SEND_YN(발송여부), RESP_YN(응답여부), RESP_YMD(응답일자 — 익명 재식별 방지 위해 일자 단위, 0-5), ACCESS_TOKEN(개인 응답 URL 토큰 — 중복응답 방지 SFR-006)
  - 등록경로: 직접등록/엑셀업로드/학사연계 (SFR-005) — LOAD_TYPE_CD로 구분
- SV_SEND_HIST: SEND_ID(PK), RESPONDENT_ID(FK), SEND_TYPE_CD(URL/QR/이메일/문자/포털공지), SEND_DT, SEND_RESULT_CD(성공/실패), RESEND_SEQ(재발송 SFR-007)

### 3-7. SV_RESPONSE (응답 헤더) / SV_ANSWER (응답 상세) ★대용량 · ★익명성 설계(0-5)
- SV_RESPONSE: RESPONSE_ID(NUMBER PK), SURVEY_ID(FK), SURVEY_YEAR(★인덱스 선두, 파티셔닝 대체), **ANON_YN**(익명여부, SV_SURVEY에서 상속), **RESPONDENT_ID(FK, 기명 시에만. 익명이면 NULL)**, SUBMIT_ST_CD(임시저장/제출완료 — SFR-006), START_DT, SUBMIT_DT(익명 조사는 일자/시간대 버킷 — 0-5 재식별 방지)
  - **★소속 스냅샷(비식별 분석용, 0-5)**: RESP_TYPE_CD(대상유형), RESP_DEPT_ID, RESP_MAJOR_ID, RESP_GRADE — 응답 제출 시 대상자 소속을 복사 저장. 개인 특정 없이 부서/학과/학년별 집계(SFR-008) 가능.
  - **★중복응답 방지(검증 중요-3 반영)**: 1차 키는 개인 응답토큰 `ACCESS_TOKEN`(SV_RESPONDENT) 또는 기명 시 RESPONDENT_ID. **IP는 중복 판단 기준으로 쓰지 않음**(기숙사·도서관 NAT 공유 IP로 정상 응답 오차단·모바일 전환 회피 발생). IP는 보관하더라도 이상탐지 보조 로그용(선택, 해시).
- SV_ANSWER: ANSWER_ID(NUMBER PK), RESPONSE_ID(FK), SURVEY_YEAR(★인덱스), SQ_ID(FK, 조사문항), **SQ_ROW_ID(FK, 행렬형 행 — 검증 치명-2 반영. 비행렬은 NULL)**, ANS_TYPE_CD, ANS_OPT_ID(선택형 답 — 다중선택은 다건 INSERT), ANS_SCORE(척도 점수), ANS_TEXT(주관식/서술형 CLOB)
  - 행렬형 저장 예: "강의내용(행)=4점, 교수법(행)=5점" → SQ_ID 동일, SQ_ROW_ID로 행 구분한 다건 INSERT.
  - **인덱스 전략(SE2)**: `IX_ANSWER_01 (SURVEY_YEAR, SURVEY_ID, SQ_ID)`, `IX_ANSWER_02 (RESPONSE_ID)`. 연도 조건 없는 전체 스캔 금지 규칙을 쿼리 표준으로 둠.

### 3-8. SV_STAT_SUMMARY (집계 스냅샷 — 성능 핵심 · ★2차원 교차 검증 반영)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| STAT_ID | NUMBER PK | |
| SURVEY_ID / SURVEY_YEAR | | 대상 조사·연도 |
| SQ_ID | | 문항 |
| SQ_ROW_ID | | 행렬형 행(비행렬 NULL) |
| DIM_TYPE_CD | | 1차 집계차원: 전체/대상/부서/학과/학년 (SFR-008) |
| DIM_KEY | | 1차 차원 키값 |
| **DIM_TYPE_CD2** | | ★2차 교차차원(단일집계는 NULL) — 교차분석용 |
| **DIM_KEY2** | | ★2차 차원 키값 (예: 학과 × 학년) |
| FREQ_CNT / RESP_CNT | | 빈도 / 응답수 |
| AVG_SCORE / STDDEV_SCORE | | 평균 / 표준편차 (SFR-008) |
| DIST_JSON | CLOB | 응답 분포(보기별 카운트) |
| **MASK_YN** | CHAR(1) | ★소집단 억제: RESP_CNT < 임계값(N) 시 'Y' → 조회·다운로드 마스킹 (0-5) |

- **용도**: 대시보드·보고서·연도추이·교차분석 모두 이 테이블을 읽음. 원자료 재집계는 조사 종료·배치 시. 3차원 이상 등 협의 외 조합은 예외적으로 원자료 조회(범위 SFR-008 협의).
