## ① 로그인 화면 삽화 (필수, 효과 최대)

- **쓰이는 곳**: 로그인 페이지 좌측 절반(데스크톱). 시스템의 첫인상이자 발표 시연의 첫 화면
- **캔버스**: 2000×1500px (가로 4:3)
- **장면 (둘 중 택1 또는 본인 아이디어)**:
  - A안: 책상 위 클립보드 설문지에 체크 표시하는 손 + 옆에 커피잔·연필 (조사 플랫폼 정체성 직관 전달)
  - B안: 노트북/휴대폰으로 설문에 응답하는 학생 2~3명 (얼굴 디테일은 점·선 정도로 단순하게)
- **구도**: 좌측정렬 화면에 배치되므로 주인공을 중앙~약간 오른쪽에

## ② 응답 완료 화면 삽화 (필수)

- **쓰이는 곳**: 학생이 설문 제출 직후 보는 완료 화면(모바일). 응답자가 가장 많이 보는 그림
- **캔버스**: 1200×1200px (정사각)
- **장면**: 종이비행기가 날아가는 모습(= 제출됨) 또는 봉투에서 나온 큰 체크 표시. 밝고 가벼운 느낌
- **주의**: 모바일에서 240px 정도로 작게 보임 → 디테일 과하지 않게, 실루엣이 명확하게

## ③ 빈 상태 삽화 (필수)

- **쓰이는 곳**: "등록된 조사가 없습니다" / "환류 과제가 없습니다" 등 목록이 빌 때
- **캔버스**: 1000×1000px (정사각)
- **장면**: 빈 서류함(트레이) 하나 + 돋보기 정도. **가장 단순하게** — 3점 중 최소 디테일
- **주의**: 화면에서 160~200px로 매우 작게 표시됨

## ④ 오류 화면 삽화 (선택)

- **쓰이는 곳**: 시스템 오류/접근 불가 안내 화면
- **캔버스**: 1000×1000px
- **장면**: 뽑혀 있는 콘센트 플러그, 또는 길 잃은 표지판 — 유머 한 스푼 OK

## ⑤ 사용가이드 헤더 삽화 (선택)

- **쓰이는 곳**: /guide.do 사용가이드 페이지 상단
- **캔버스**: 2400×800px (가로 3:1 배너)
- **장면**: 설문 생성→배포→분석→개선의 여정을 한 줄로 (화살표로 이어진 4개 소품: 연필→종이비행기→차트→새싹 등)
