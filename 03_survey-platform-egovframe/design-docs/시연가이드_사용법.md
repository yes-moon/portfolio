## 2. 🚀 빠른 시연 (이미 만들어둔 데모로 결과부터 보기) — 추천 먼저!
**admin 로그인 → "조사운영" 클릭 → "2026 재학생 교육만족도 시범조사"(진행중) 클릭**
이 조사엔 문항·응답·IPA·환류·대상자가 미리 들어 있어 모든 결과 화면을 바로 볼 수 있습니다.

조사 상세 화면에서 아래 버튼들을 눌러보세요:
1. **📊 응답 통계 보기** — 문항별 평균·표준편차, 점수 분포 막대, 선택형 빈도표, 서술형 답변
   - 이 화면에 **⬇원자료 엑셀(+코드북)**, **⬇기술통계 CSV** 다운로드 버튼도 있음 (눌러서 엑셀 열어보기)
2. **🎯 IPA 분석** — 만족도·중요도 표 + GAP + 사분면 산점도. "Ⅱ 중점개선" 항목이 빨간 표시
   - 표 오른쪽 **[부서 선택 + 과제 생성]** 버튼 → 개선과제 자동 생성(환류로 연결)
3. **🔀 교차분석** — 상단 탭(학부별/학년별/캠퍼스별) 전환. 5명 미만 집단은 `·`로 가려짐(개인정보 보호)
4. **👥 대상자 관리** — 대상자 명단·개인 응답 URL·응답률. 여기서 대상자 생성도 가능
- 환류 결과는 상단 메뉴 **"환류관리"**에서: 개선과제 목록(담당부서·차년도 점검연도)

## 3. 🛠️ 처음부터 새 설문 만들어보기 (전체 흐름 체험)
**admin 로그인 → 조사운영 → 우측 "새 조사" 또는 목록 상단 등록**

### ① 조사 등록
- 조사명(예: "테스트 조사"), 연도, 유형(만족도), 시작일·종료일 입력 → 등록
- 등록하면 조사 상세로 이동(상태 = READY 준비)

### ② 문항 추가 (2가지 방법)
- **일반 문항 추가**: 문항 내용 입력 → 유형 선택
  - `5점 척도` (매우만족~전혀) / `단일선택`(보기는 한 줄에 하나씩) / `서술형`
- **IPA 항목 추가**(2025 조사 방식): 항목 하나 입력 → **[만족도]+[중요도] 두 문항 자동 생성**
  - 항목코드(예: A1)와 시작순번 지정 → "만족도·중요도 쌍 생성"

### ③ 조사 시작
- 문항을 몇 개 넣은 뒤 **▶ 조사 시작(OPEN)** 클릭
- 그러면 **응답 URL**이 발급됨(파란 박스). 이 링크가 응답자에게 배포하는 주소

### ④ 응답해보기 (익명)
- 발급된 응답 URL을 **새 탭/새 브라우저(또는 시크릿창)**에 붙여넣기
- 로그인 없이 응답 화면이 뜸 → 소속 학과·학년 선택 + 문항 답변 → 제출
- 여러 번 제출해보며 응답 쌓기(익명이라 계속 가능)

### ⑤ 결과 확인
- 다시 admin 화면 → 그 조사 → 📊통계 / 🎯IPA / 🔀교차분석에서 방금 응답이 반영된 것 확인

### ⑥ (선택) 대상자 기반 1인1응답
- 조사 상세 → 👥대상자 관리 → 학과·학년·인원 지정해 "대상자 생성"
- 생성된 **개인 응답 URL**(표 오른쪽)을 복사해 응답 → 제출
- **같은 URL로 다시 응답 시도하면 "이미 응답" 차단**(중복방지 확인 포인트)

## 4. 화면·기능 한눈 정리
| 하고 싶은 것 | 가는 길 |
|---|---|
| 로그인/권한 차이 | admin vs user01 로그인 비교 |
| 설문 만들기 | 조사운영 → 새 조사 → 문항 추가 → 시작 |
| 응답 받기 | 시작하면 나오는 응답 URL 배포 |
| 통계 보기 | 조사 상세 → 📊 응답 통계 |
| IPA(중요도-만족도) | 조사 상세 → 🎯 IPA 분석 |
| 학부/학년/캠퍼스 비교 | 조사 상세 → 🔀 교차분석 |
| 개선과제(환류) | IPA에서 과제 생성 → 상단 "환류관리" |
| 대상자·중복방지 | 조사 상세 → 👥 대상자 관리 |
| 엑셀/CSV 내보내기 | 응답 통계 화면의 ⬇ 버튼 |
