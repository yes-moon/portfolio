# 온라인 설문 시스템

문항 렌더링부터 응답 수집 · 집계 · 내보내기까지 담당한다.

## 기능

- **문항 렌더링** — 단일선택 · 복수응답 · 매트릭스 · 주관식을 정의대로 그린다
- **중복 응답 차단**
- **관리자 대시보드** — 응답 현황과 집계
- **일일 메일 리포트** — cron으로 매일 아침 발송
- **SPSS `.sav` 내보내기** — `pyreadstat`으로 변환해 통계 도구에 바로 올릴 수 있게 했다

마지막 항목이 실제로 가장 요긴했다. 통계 담당자가 CSV를 받아 변수 레이블과 값 레이블을
다시 입력하던 일이 없어졌다.
