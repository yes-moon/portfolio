# 사주 SaaS

만세력 계산 엔진을 독립 마이크로서비스로 분리하고, 결제·인증 코어 API를 붙인 서비스.

## 구성

| 모듈 | 역할 |
|---|---|
| 만세력 엔진 | 생년월일시 → 사주 기둥·십성·대운. 독립 서비스라 다른 제품에서도 호출 가능 |
| 코어 API | 회원·결제·권한 (JWT) |
| PHP 프런트 | 사용자 화면 |
| LLM 평가 랩 | 해석 생성용 로컬 모델 비교 |

## 시간대가 결과를 바꾼다

사주는 태어난 **시각**이 기준이라 시간대 처리가 그대로 결과에 반영된다.
한국은 표준시 자오선이 네 번 바뀌었고 서머타임도 있었는데, 이걸 무시하면 시주(時柱)가 통째로 틀린다.

| 기간 | 자오선 |
|---|---|
| ~1908-04 | 127.5° (한성 지방시 근사) |
| 1908~1912 | 127.5° (대한제국 UTC+8:30) |
| 1912~1954 | 135° (UTC+9) |
| 1954~1961 | 127.5° (UTC+8:30) |
| 1961~ | 135° (현행 KST) |

여기에 경도 보정(1도 = 4분)과 서머타임 해제를 더해 진태양시를 구한다.
