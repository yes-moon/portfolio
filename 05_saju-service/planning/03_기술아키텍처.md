## 2. 기술 스택 선택 이유

| 영역 | 선택 | 이유 |
|---|---|---|
| 백엔드 언어 | **Python (FastAPI)** | [대표자] 사업 분야 일치, LLM 생태계 최강, 작은아들 학습 영역 |
| 프론트엔드 | **Next.js + React** | 빠른 SSR, SEO, 인증 통합 |
| 앱 (Phase 3) | **React Native** | 코드 공유, 빠른 출시 |
| LLM 서빙 | **vLLM** | RTX 3090 최적화, 연속 배치, OpenAI API 호환 |
| 만세력 | **sxtwl** | 24절기 정확, 중국 만세력 표준 |
| RAG | **BGE-M3 + ChromaDB** | 한국어·한자 모두 강함, 가벼움 |
| DB | **PostgreSQL 16** | JSON·전문검색 강함, 안정성 |
| 캐시 | **Redis 7** | 표준 |
| 결제 | **토스페이먼츠** + 이니시스 | 한국 표준 |
| 인증 | **NextAuth (카카오·네이버)** | 가입 마찰 최소화 |
| 모니터링 | **Grafana + Prometheus** | 표준, GPU exporter 지원 |

## 3. LLM 파이프라인 (사주 보고서 1건 생성 흐름)

```
사용자 입력 (생년월일시·이름)
  ↓
[1] 만세력 Engine → 명조 8글자 + 대운·세운 산출
  ↓
[2] 명조 → JSON 구조화
  · 천간·지지·십성·격국 후보·용신 후보
  · 합충·형해·신살
  ↓
[3] RAG 검색 (BGE-M3)
  · [대표자] 풀이 코퍼스 검색
  · 유사 명조 사례 Top-10
  · 격국별 표준 풀이 패턴
  ↓
[4] 리랭킹 (bge-reranker-v2-m3)
  · Top-10 → Top-3
  ↓
[5] LLM 생성 (Qwen3 32B Q5)
  · 구조화 명조 + RAG 컨텍스트 + 프롬프트 템플릿
  · 섹션별 생성 (격국·용신·5년 운세·건강·재물·관계)
  · 1만~3만 토큰 출력
  ↓
[6] 후처리
  · [대표자] 사전 정의 규칙 적용
  · 의료·법규 표현 필터
  · 마크다운 → PDF (WeasyPrint)
  ↓
[7] 저장·전달
  · PostgreSQL 보고서 메타
  · S3(MinIO) PDF 저장
  · 사용자 이메일·앱 알림
```

평균 처리 시간 (Qwen3 32B Q5, vLLM 배치):
- 베이직 (2,000 토큰): 3~5초
- 스탠다드 (10,000 토큰): 15~25초
- 프리미엄 (30,000 토큰): 45~80초
- 가족 패키지 (100,000 토큰, 4명): 3~5분

## 4. 비전 파이프라인 (만세력 그림 자동 판독)

사용자가 다른 만세력 앱 스크린샷을 업로드하면:
```
이미지 업로드 → Qwen2.5-VL 7B 판독
              → 8글자 + 대운 추출
              → 만세력 라이브러리 결과와 교차 검증
              → 일치 시 진행 / 불일치 시 재시도·사용자 확인
```

이게 [대표자]이 노트북 작업에서 검증한 방식 (만세력 계산 LLM에 시키지 말고 그림 판독).

## 5. RAG 시드 데이터 — 회사 핵심 IP

**가장 중요한 자산**: [대표자] 박사의 풀이 코퍼스

| 데이터 종류 | 수량 (목표) | 출처 |
|---|---|---|
| 가족·지인 풀이 케이스 | 100~500건 | [대표자] 누적 |
| 격국별 표준 풀이 패턴 | 50~100건 | [대표자] 정리 |
| 명리 고전 인용 (자평진전·궁통보감) | 200~500단락 | 공개 자료 |
| 사주명리 학술 자료 | 50~100건 | [대표자] 박사 학술 라인 |

→ Phase 0에서 100건 시드 구축. Phase 2 이후 누적 보고서·피드백으로 자동 확장.

## 7. 개발·배포 워크플로우

```
로컬 개발 (server01 또는 노트북)
  ↓
git push → GitHub Private Repo
  ↓
GitHub Actions
  ├─ pytest (백엔드 테스트)
  ├─ Vitest (프론트엔드)
  ├─ Docker build
  └─ server01로 SSH 배포 (Docker Compose pull + restart)
  ↓
server01에서 무중단 배포 (Blue-Green)
```

## 8. 개발 우선순위 (Phase 1 MVP)

1. **Week 1~2**: 만세력 Engine + 명조 JSON 구조화
2. **Week 3~4**: vLLM Qwen3 32B 서빙 + 프롬프트 템플릿
3. **Week 5~6**: RAG 시드 100건 + ChromaDB + BGE-M3
4. **Week 7~8**: FastAPI 백엔드 + 결제 + 인증
5. **Week 9~10**: Next.js 프론트 + 무료·베이직 UI
6. **Week 11~12**: PDF 생성·이메일·관리자 페이지
7. **Week 13~14**: 베타 100명 모집·피드백·정정
8. **Week 15~16**: 정식 출시 준비
