## 2. 포지셔닝

### 2-1. 핵심 포지셔닝 선언
- **Who**: 20~34세 한국 여성 (1차 타깃)
- **When**: 아침 출근·등교길 5분, 잠들기 전 10분
- **What**: 내 사주를 AI가 매일 새롭게 읽어주는 감성 다이어리
- **Why**: 불확실한 내 삶을 이해하고 싶고, 친구와 나누고 싶음
- **How not**: 한자 범벅 전문 사주 X, 얕은 오늘의 운세 X

### 2-2. 차별화 4축

| # | 축 | 구체 내용 |
|---|---|---|
| 1 | **개인화 AI 해석** | 템플릿 아님 — 생년월일×오늘 날짜×질문 결합하여 Qwen/Claude 실시간 생성 |
| 2 | **구독 모델** | 단건 결제 지옥 탈피, 월 9,900원 LTV 극대화 |
| 3 | **감성 UI** | Co-Star × 포스텔러 하이브리드, 미니멀 + 한국적 |
| 4 | **커뮤니티** | 친구 궁합 비교, 오늘의 힐링 카드 공유, 익명 고민 상담 |

## 3. 제품 기능 기획

### 3-1. MVP 핵심 기능 (런칭 시점)

1. **사주 기본 명식 + 한 줄 해석** (무료)
2. **오늘의 운세 카드 3줄** (무료) + **심층판** (유료)
3. **월간 운세 리포트** (유료, 구독 시 무제한)
4. **궁합 분석 (2인 비교)** (유료)
5. **작명 (아기·반려동물·사업체)** (유료)
6. **택일 (결혼·이사·개업)** (유료)
7. **일기장 + 오늘의 에너지 추천**

### 3-2. 확장 기능 (런칭 후 3~6개월)
- AI 채팅 사주 상담사 (LLM 기반)
- 친구 초대 + 궁합 월드 (바이럴)
- 프리미엄 연간 리포트 (PDF)
- 실시간 역술인 연결 (마켓플레이스 중개 수수료)
- 영문판 / 일문판 (해외 진출)

### 3-3. 현재 보류 항목
- **부적 생성 서비스** — 디자인 품질 만족 전까지 개발 보류 (Saju4 연구자료만 보존)

## 5. 기술 아키텍처

```
[사용자 앱/웹]
     ↓
[API 게이트웨이 (FastAPI 또는 NestJS)]
     ├─→ [만세력 엔진]     ← lunar-python + 자체 검증
     ├─→ [사주 해석 LLM]   ← GPU 0: qwen3.5:27b (자체 서버)
     ├─→ [챗봇 LLM]        ← 동일 GPU 공유 / Claude API
     ├─→ [추천 엔진]       ← 오행 기반 개인화
     ├─→ [결제 (포트원)]
     ├─→ [푸시 (FCM / 카카오 알림톡)]
     ↓
[DB: PostgreSQL + Redis]
[스토리지: S3]
[분석: Mixpanel + GA4]
[모니터링: Sentry]
```

### 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트 웹 | Next.js 15 + TS + Tailwind | SEO·SSR, 빠른 개발 |
| 프론트 앱 | React Native (Expo) | 웹 코드 재활용 |
| UI | shadcn/ui + Framer Motion | 감성 애니메이션 |
| 상태관리 | Zustand + TanStack Query | 경량 |
| 백엔드 | FastAPI (Python) | LLM·만세력 라이브러리 유리 |
| DB | PostgreSQL | 복잡 쿼리 |
| 캐시 | Redis | 운세 결과 캐싱 |
| 인증 | Firebase Auth / Supabase | 카카오·네이버·애플 연동 |
| 결제 | 포트원(아임포트) | 국내 PG 표준 |
| SMS/알림톡 | NHN Toast / 쿨에스엠에스 | 건당 8~13원 |
| LLM | qwen3.5:27b (자체) + Claude API (프리미엄) | 하이브리드 |

### 하드웨어 (자체 보유)
- **AMD Ryzen 9 5950X + 128GB RAM + RTX 3090 × 2 (VRAM 48GB)**
- MVP 단계: 현재 PC로 LLM + 이미지 생성 전부 커버 가능
- 유저 1만 명 이후 클라우드 GPU 병행 고려
