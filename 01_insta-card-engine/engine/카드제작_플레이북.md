## 0. 일하는 방식부터 (가장 중요)

`D:\fable 5 작업용\fable5_행동양식_이식프롬프트_company.md`를 읽고, "=== 프롬프트 시작 ===" 이후의 원칙을 이 프로젝트의 작업 규범으로 삼을 것. 카드 제작에서 특히 지킬 것:

- **렌더한 PNG는 전부 Read로 직접 열어 확인한다.** "됐을 것"이라고 보고하지 않는다. 확인 항목: 글자 깨짐(두부), 텍스트 넘침, 정렬, 명도 대비, 날짜·숫자 논리.
- **날짜·숫자는 오늘 날짜 기준으로 재검산한다.** 실제 사고 사례: 유료 전환일이 7/8인데 7/6에 "내일부터 유료"라고 썼다가 지적받음. D-day 표기는 기준일이 애매하면 "무료는 내일까지"처럼 날짜 논란 없는 표현으로.
- **외부 뉴스·사실은 기준일 명시 + "변동 가능" 고지.** 기사 문장을 그대로 옮기지 않는다(저작권) — 사실만 추려 자기 문장으로. 직접 검증 못 한 내용은 사용자 확인에 의존했음을 인지하고 고지문으로 방어.
- **과장 금지, 한계는 카드에서도 말한다.** "능력은 이식되지 않습니다" 같은 정직 카드가 이 계정을 낚시 계정과 구분 짓는 차별점이다.

## 1. 제작 사이클 (매 게시물 반복)

1. **구성안 먼저 제시**: 카드 장별 한 줄 요약 + 강조색 + 콘셉트를 사용자에게 보여주고 방향 확정 후 제작. (판단 근거와 리스크— 브랜드 톤 충돌 등—도 이때 한 번만 말한다)
2. `posts\{번호_주제}\build.ps1` 작성. 첫 줄 `. (Join-Path $PSScriptRoot '..\..\_engine\v6.ps1')`, `$ACCENT` 1색 지정, `$O=$PSScriptRoot`.
3. **BOM 재저장 후 실행** (한 줄 패턴):
   `$p='...build.ps1';$c=Get-Content -Raw -Encoding UTF8 $p;[IO.File]::WriteAllText($p,$c,(New-Object Text.UTF8Encoding($true)));& $p`
4. PNG 전수 Read 검수 → 수정 → 재렌더 (문제 없을 때까지).
5. `캡션.txt` 작성 (6절 참고).
6. **피드백은 사건이 아니라 정책**: 한 번 지적받은 것(예: DIM 색 남용, 선언형 카피)은 그 카드만이 아니라 전 카드·이후 작업에 적용.

## 2. 디자인 판단 원칙 (v6 위에서 확립)

- **카드마다 정보그래픽 형식을 바꾼다**: 표지(아이콘+배지+대형타이포) → 에디터/브라우저 목업 → 타임라인 → 초대형 숫자 → 체크리스트/대조 → CTA. 같은 형식 연속 2장 금지 — 넘길 때 시각적 리듬이 생기고, 이것이 "글자 카드 나열" 대비 결정적 품질 차이.
- **강조색(라임 등 $ACCENT)은 결론에만**: 마감일, 가격, 핵심 한 줄. 나머지는 무채색 위계로.
- **명도 위계 규칙**: `$WHITE` = 핵심 본문·행동 유도 / `$SLATE` = 설명·보조 / `$DIM` = 날짜 스탬프 등 부차 정보 전용. **중요 정보에 $DIM 금지** (가독성 지적받은 사항).
- **최고 강조 = 라임 배지**: accent 배경 채움 + 남색 `FromArgb(10,16,28)` 글자. 명도 대비가 카드에서 가장 세다. 카드당 1개만.
- **제목은 내용 설명형**: "프롬프트를 드립니다"처럼 뭘 주는지/뭘 말하는지 그대로. 분위기형 카피, "~는 ~입니다" 선언형 반복은 "AI티"로 지적받음.
- 핵심 오퍼(주는 것·받는 법)는 표지와 2번 카드 안에서 완결. 배경 설명은 그 뒤로.
- 타사 브랜드(클로드 등) 언급 게시물은 해당 브랜드 아이콘을 표지에 재현해 "무슨 소식인지" 0.5초 안에 알게 한다.

## 5. PowerShell 함정 (CLAUDE.md 5절 + 이번 세션 추가분)

- 지역변수 `$w`·`$h` 금지 — 대소문자 미구분이라 캔버스 `$W/$H` 오염. `$ww,$mx,$my,$phh,$lxx` 식으로 회피.
- 함수명 `R`, `AC` 금지 (기존 규칙). 신규 함수도 엔진 함수명과 충돌 확인.
- 텍스트 문자열은 전부 **작은따옴표** — `'$10'`처럼 `$` 든 텍스트가 큰따옴표에서 변수로 해석되는 사고 방지.
- `Select-String`은 매치 여러 개면 `.LineNumber`가 배열 — 마커 찾기는 라인 완전일치(`.Trim() -eq`) 루프로.
- PSScriptAnalyzer의 "`$ACCENT` 미사용" 경고는 엔진이 동적 스코프로 읽는 구조라 **오탐, 무시**.
- 금지 글리프(→·↓·² 등, 두부 발생)와 「」 같은 미확인 글리프는 렌더 텍스트에 쓰지 말 것. 따옴표는 `"..."` 안전.
