## 5. D 드라이브 폴더 동기화 (★ 핵심)

데스크톱의 D 드라이브 작업 폴더(`d:/2026년[A대학교]_구매팀`, `D:/서베이 자동화`, `D:/[논문통계브랜드]`)를 노트북에서도 같은 경로로 접근하려면 **OneDrive 동기화**가 가장 단순함.

### 5.1 데스크톱에서 (1회만)
1. **OneDrive 설치**: https://www.microsoft.com/microsoft-365/onedrive/download (이미 Windows 11에 기본 설치)
2. `user@example.com` 또는 Microsoft 계정 로그인
3. 동기화할 폴더 추가:
   - `D:/2026년[A대학교]_구매팀` → 마우스 우클릭 → "OneDrive에 백업"
   - `D:/서베이 자동화` → 동일
   - `D:/[논문통계브랜드]` → 동일 (선택, 100GB 가까이 크면 제외)
4. 클라우드 업로드 완료 대기 (수 GB → 수십 분 소요)

### 5.2 노트북에서
1. 동일 OneDrive 계정 로그인
2. 해당 폴더 "이 PC에서 항상 사용 가능"으로 설정 → 자동 다운로드
3. 끝. **데스크톱과 동일 경로로 접근 가능**

### 5.3 대안 — 외장 SSD (인터넷 불안정한 환경 권장)
- 1TB SSD (USB-C) → 데스크톱·노트북 양쪽에서 D 드라이브로 인식
- D 드라이브 작업 폴더를 외장 SSD에 두고 그대로 꽂아서 사용
- 단점: 노트북·데스크톱 동시 작업 불가

### 5.4 대안 — Git (코드만)
- `D:/서베이 자동화/`를 Git Private Repo로 → 코드만 동기화
- 데이터(docx, xlsx)는 별도 Google Drive
- 자세한 내용은 §11 부록

## 7. Claude Code 메모리·CLAUDE.md (★ 작업 일관성)

### 7.1 프로젝트별 CLAUDE.md (자동 인식)
- `D:/2026년[A대학교]_구매팀/CLAUDE.md` 같은 프로젝트 폴더에 있는 파일은 OneDrive 동기화로 자동 따라옴
- 노트북에서 해당 폴더 열면 Claude Code가 자동 인식

### 7.2 사용자 자동 메모리 (선택, 고급)
- 위치: `C:\Users\<사용자>\.claude\projects\d--2026--------\memory\`
- 동기화 방법:
  - **간단**: 데스크톱에서 메모리 폴더 통째로 압축 → OneDrive 업로드 → 노트북에서 다운로드 후 같은 위치에 압축 해제
  - **고급**: 심볼릭 링크로 OneDrive 폴더 → `.claude/projects/.../memory` 연결
    ```powershell
    # 노트북에서 (관리자)
    cmd /c mklink /D "C:\Users\$env:USERNAME\.claude\projects\d--2026--------\memory" "C:\Users\$env:USERNAME\OneDrive\claude_memory\d--2026--------"
    ```

### 7.3 대안 — 메모리 동기화 안 하고 시작
- 노트북에서는 새 메모리로 시작
- CLAUDE.md만 동기화되면 프로젝트 컨텍스트는 충분히 복원됨

## 9. 자주 발생하는 문제

| 증상 | 해결 |
|------|------|
| `python` 명령어 안 먹힘 | Python 설치시 "Add to PATH" 체크 안 했음. 재설치 |
| `pip install` 인증 오류 | 회사 프록시면 `pip install --proxy=http://proxy:port ...` |
| Google Drive `G:` 안 보임 | Drive for desktop 트레이 아이콘 → "스트리밍" 모드 활성 확인 |
| OneDrive 동기화 멈춤 | 트레이 아이콘 → "동기화 일시 중지" 해제 |
| 한글 콘솔 깨짐 | `chcp 65001` 또는 `$env:PYTHONIOENCODING="utf-8"` |
| Claude Code 로그인 실패 | 브라우저 → claude.ai 로그인 후 재시도 |
| 환경변수 변경 후 적용 안 됨 | PowerShell·VS Code 모두 종료 후 재시작 |

## 11. Git Private Repo 동기화 (부록 — 선택)

### 11.1 GitHub Private Repo 생성

4. Create repository

### 11.2 데스크톱에서 push (1회)
```powershell
cd "D:\서베이 자동화"

# .gitignore 작성 (토큰·데이터 제외)
@"
# 토큰·민감 정보

"@ | Out-File -Encoding utf8 .gitignore

git init
git add .
git commit -m "초기 설정"
git remote add origin user@example.com:company/citya-2026.git
git push -u origin main
```

### 11.3 노트북에서 clone (1회)
```powershell
cd D:\
git clone user@example.com:company/citya-2026.git "서베이 자동화"
```

### 11.4 일상 동기화
```powershell

# 다음 날 노트북에서
git pull
```

⚠ 주의: 토큰·답례품 수령 정보 등 민감 데이터는 절대 커밋하지 말 것 (`.gitignore` 철저히)
