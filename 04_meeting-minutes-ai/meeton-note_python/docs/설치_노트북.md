# 미팅온 노트 — 발표 노트북 설치 안내 (Windows, CPU 전용 기준)

> 인터넷은 **설치할 때만** 필요합니다. 설치 후에는 전 과정 오프라인.
> 소요: 다운로드 약 4~5GB(모델) 포함 30~60분.

## 1. 준비물
- Windows 10/11, RAM 16GB 권장(8GB면 LLM을 qwen2.5:1.5b로), C: 여유 15GB
- Python 3.11 (3.10~3.12 가능. 3.13은 피할 것) — https://www.python.org/downloads/ 설치 시 **Add python.exe to PATH** 체크
- Ollama — https://ollama.com/download (설치 후 트레이에 상주)
- Microsoft Edge(기본 설치) — 앱 창 모드로 실행

## 2. 파일 복사
`D:\meeton-note\` 폴더 전체를 USB로 복사(models\ 포함 시 whisper 다운로드 생략 가능, 약 2GB).
`data\`는 비워도 되고, 시연용 회의를 미리 만들어 둔 상태로 복사해도 됩니다.

## 3. 설치 (PowerShell)
```powershell
cd D:\meeton-note
python -m pip install -U pip
pip install fastapi "uvicorn[standard]" python-multipart faster-whisper python-docx
ollama pull qwen2.5:3b        # LLM — 질의응답용 (약 2GB, 답변 30~50초)
ollama pull qwen2.5:7b        # LLM — 회의록·화자 추정용 (약 4.7GB, 회의당 1회 2~3분. 3b는 화자 구분을 못 함)
ollama pull bge-m3            # 임베딩 (약 1.2GB)
python -c "from faster_whisper import WhisperModel; WhisperModel('medium', device='cpu', compute_type='int8', download_root=r'D:\meeton-note\models'); print('ok')"
```
whisper 모델 폴더(`models\`)를 함께 복사했다면 마지막 줄은 즉시 ok.

## 4. Windows 권한
설정 → 개인 정보 및 보안 → **마이크**: "앱이 마이크에 액세스하도록 허용" 켬, **데스크톱 앱 허용** 켬. **카메라**도 동일.
Edge 첫 실행 시 주소창 왼쪽 자물쇠에서 마이크·카메라 **허용**.

## 5. 실행
`START.bat` 더블클릭 → Ollama·서버가 뜨고 Edge 앱 창이 열립니다(최대 80초). 검은 서버 창은 최소화만.
수동 실행: `python -m app.server` 후 브라우저에서 http://127.0.0.1:8765/

## 6. 설정 조정 (화면 우상단 ⚙ 또는 `config.json`)
| 상황 | 값 |
|---|---|
| 4코어 이하·전사가 너무 느림 | whisper_model = small |
| RAM 8GB | llm_model = qwen2.5:1.5b |
| GPU(NVIDIA) 있음 | whisper_device = cuda, whisper_compute = float16 (CUDA 12 + cuDNN 필요) |
| 발화 청크가 너무 잦음 | live_chunk_sec = 10 |

## 7. 점검 (발표 전날)
1. 새 회의 → 녹음 30초 말하기 → 실시간 전사가 뒤따라 나오는지
2. 정지 → "전사 완료" 배지 → 발화 목록에 화자 라벨(추정) 붙는지
3. [회의록 생성] → 30초~1분 안에 초안(요약·논의·결정·요청사항) 나오는지
4. 검색·질의 탭에서 질문 1개 → 출처 [1][2] 붙은 답이 나오는지
5. 카메라 켜기 → 촬영 → 회의 정보·사진 탭에 사진이 보이는지
6. 내보내기 ▾ → 회의록 DOCX 열리는지
문제 시: 서버 창의 오류 메시지 확인 → `python -m app.server`를 직접 실행하면 전체 로그가 보입니다.

## 8. 시연 데이터 사전 준비
발표장에서 라이브 녹음은 1~2분만. 그 전에 **미리 만든 회의 2~3건**(전사·회의록·승인 완료)을 `data\`에 넣어 두어 검색·질의가 바로 되게 합니다. 이 PC에서 만든 `data\` 폴더를 그대로 복사하면 됩니다.
