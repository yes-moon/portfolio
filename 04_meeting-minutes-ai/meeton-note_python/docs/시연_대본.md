"회의를 이 노트북으로 녹음하면 전사·회의록 초안·검색이 전부 노트북 안에서 처리됩니다. 인터넷도, 외부 서버도 쓰지 않습니다. 화자는 문맥으로 추정하고 이름 확정은 서기가 합니다. 보고서는 이 도구가 쓰는 게 아니라 연구진이 씁니다 — 이건 기록과 근거 검색 도구입니다."

## 사전 준비 (발표 전날·당일 아침)
- 노트북: `START.bat` → Edge 앱 창. 상단 상태 3개가 초록(STT small→medium · LLM qwen2.5:3b · 회의록 qwen2.5:7b · bge-m3).
- `data\`에 **미리 만든 회의 3건**(전사·화자·회의록·승인 완료, 사진 2~3장 포함) — 기관별로 [A시]·교육지원청·특구센터 1건씩. 검색·질의는 이 3건 위에서 한다.
- 새 회의 1건은 **빈 상태로 미리 생성**(회의명·기관·안건·참석자 입력해 둠) — 라이브 녹음용.
- 마이크는 노트북 내장 또는 이어폰 마이크. 발표자 본인이 마이크 가까이에서 30~40초 말한다.
- 창 배치: 앱 창 하나만. 탭은 「녹음」에 둔다.
- 라이브 발화 원고(아래 §라이브 원고)를 노트북 옆에 인쇄.

"실제 화면입니다. 왼쪽이 녹음에서 전사된 발화문 — 화자 라벨은 추정이라 표시돼 있고 — 오른쪽이 과업지시서 서식 그대로 나온 회의록 초안입니다. 요약·주요 논의·결정사항·회의결과·**기관별 요청사항과 반영계획**. 아래 관리대장 CSV와 회의록 DOCX로 바로 내보냅니다. 15회 회의를 이 흐름으로 기록하고, 요청사항 반영 여부를 최종보고서 별도 장으로 냅니다."

## B. 90초 (질의 시 기본)
1. **녹음 탭** (10초): "노트북 마이크로 녹음하고, 로컬 STT가 8초 단위로 자막처럼 따라옵니다. 회의 중 필요한 장면은 카메라로 찍어 회의 기록에 붙입니다." — 미리 만든 회의의 사진 썸네일을 가리킴.
2. **전사·회의록 탭** (40초): A와 동일 + "정지하면 큰 모델이 전체를 한 번 더 정밀 전사하고, 발화자를 문맥으로 나눕니다. 라벨은 추정이라 서기가 클릭해 이름을 확정합니다."
3. **검색·질의 탭** (40초): 미리 준비한 질문 1개 입력 → "전체 회의" 범위.
   - 예: "교육지원청이 제출하기로 한 자료와 기한은?" → 답변에 [1][2] 출처, 펼치면 해당 회의·시각 구간.
   - "세 기관 회의록이 로컬 벡터 색인에 쌓여 있어서, 최종보고서 쓸 때 '누가 무엇을 요청했고 어떻게 반영했나'를 근거와 함께 꺼냅니다. 답변은 CPU 노트북이라 30~40초 걸립니다." (기다리는 동안 다음 문장) "이 검색은 미팅온의 팩트온 RAG와 같은 방식이고, 성과자료 5,853건 검증에 쓴 엔진입니다."

## C. 3분 (요청 시 — 라이브 녹음)
> 라이브는 반드시 마지막. 실측(4코어 CPU): 정지 후 정밀 전사 ≈ 녹음 길이 × 0.7 → 화자 추정(7B) 2~3분 → 회의록(7B) 3~4분. **35초 녹음이면 결과까지 6~7분**이므로 녹음을 먼저 걸어 두고 그 사이 B의 검색을 보여 준 뒤 돌아온다. 회의록 생성 버튼은 화자 추정 중에도 눌러 두면 "대기 중" 표시 후 자동으로 이어진다. 시간이 없으면 전사문까지만 보여 주고 회의록은 미리 만든 회의(A)로 대체.
1. 미리 만든 빈 회의 열기 → 녹음 탭 → **녹음 버튼** → 라이브 원고를 35초 읽는다(두 사람이면 더 좋다: "특구센터에서 말씀드리겠습니다" 식으로 기관을 말머리에 붙일 것 — 화자 추정이 여기에 걸린다).
2. 읽는 동안 **카메라 켜기 → 촬영** 1장 ("화이트보드·자료를 회의 시각과 함께 남깁니다").
3. 자막이 8~15초 뒤따라 나오는 것을 보여 주고 **정지**. "이제 전체를 정밀 전사하고 화자를 추정합니다. 1~2분 걸립니다."
4. 그 사이 검색·질의(B-3) 또는 관리대장 미리보기(회의 정보 탭)를 보여 준다.
5. 돌아와서 전사·회의록 탭: 발화문 + 화자 라벨 → **[회의록 생성]** 클릭 → "7B 모델이 회의록 초안을 씁니다. 2~3분." → 시간이 없으면 "결과는 미리 만든 회의와 같은 형식입니다"로 A 화면으로 대체.
6. 결과가 나오면 요청사항 표를 가리키며 "이게 관리대장 '반영결과' 칸과 최종보고서 반영 여부 장의 원천입니다." → 내보내기 ▾ → 회의록 DOCX.
