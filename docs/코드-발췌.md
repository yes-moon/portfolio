## 1. 카드뉴스 렌더링 엔진 — 컴포넌트 분리

`01_insta-card-engine` · PowerShell 5.1 + .NET GDI+

카드 종류를 함수 단위 컴포넌트로 나눠, 글과 데이터만 바꿔 끼우면 다른 구성의 카드뉴스가 나오도록 했다. 표지·본문·비교·통계·타임라인·체크리스트·CTA가 각각 하나의 함수다.

```powershell
function CoverV7   ($path, $kick, $badge, $hl, $offer, $sub)                  # 표지
function TextCard  ($path, $page, $kick, $l1, $l2a, $l2b, $bodyArr, $sub)     # 본문
function VsCard    ($path, $page, $kick, $hpre, $hacc, $bLabel, $bLines, ...) # 비교
function BigStat   ($path, $page, $kick, $hpre, $hacc, $two, $coTitle, ...)   # 큰 숫자 강조
function TimeCard  ($path, $page, $kick, $hpre, $hacc, $nodes)                # 타임라인
function CheckCard ($path, $page, $kick, $hpre, $hacc, $items)                # 체크리스트
function CTACard   ($path, $page, $sub, $cta, $line, $link)                   # 마무리
```

별도 런타임 설치 없이 윈도우에서 바로 돌아가야 했기 때문에, 이미지 라이브러리 대신 .NET에 내장된 GDI+(`System.Drawing`)로 텍스트·도형·이미지를 직접 그렸다.

## 2. PHP MVC — DB 연결 싱글톤

`02_web-sites-php` · PHP 8 + PDO

프레임워크 없이 직접 만든 코어의 일부. 요청당 커넥션 하나만 열고, 예외 모드와 프리페어드 스테이트먼트를 기본값으로 강제한다.

```php
class Database
{
    private static ?PDO $instance = null;

    public static function getInstance(): PDO
    {
        if (self::$instance === null) {
            $dsn = 'mysql:host=' . DB_HOST . ';dbname=' . DB_NAME . ';charset=' . DB_CHARSET;
            $options = [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,   // 진짜 프리페어드 — SQL 인젝션 차단
            ];
            self::$instance = new PDO($dsn, DB_USER, DB_PASS, $options);
        }
        return self::$instance;
    }

    private function __construct() {}
    private function __clone() {}
}
```

`ATTR_EMULATE_PREPARES => false`가 핵심이다. 기본값(에뮬레이션)에서는 드라이버가 문자열을 직접 끼워 넣기 때문에, 이 값을 꺼야 DB가 쿼리와 값을 분리해서 처리한다.

## 4. 회의록 AI — 의미 검색

`04_meeting-minutes-ai` · Python + bge 임베딩 + NumPy

회의록을 조각으로 나눠 벡터로 저장해 두고, 질문이 들어오면 코사인 유사도로 가까운 조각을 찾는다. 정규화된 벡터라 내적 한 번이면 전체 유사도가 나온다.

```python
def search(query: str, topk: int, meeting_id=None) -> list:
    docs, meta, vec = _load()
    if not len(meta):
        return []

    q = llm.embed([query])[0]
    sims = vec @ q                 # (N, D) @ (D,) → 전체 유사도 한 번에
    idx = np.argsort(-sims)

    out = []
    for i in idx:
        x = meta[i]
        if meeting_id and x.get("meeting_id") != meeting_id:
            continue
        pos = f"{db.fmt_t(x['t0'])}~{db.fmt_t(x['t1'])}" if x.get("t0") is not None else ""
        out.append({"score": round(float(sims[i]), 3), "pos": pos, "chunk": x["chunk"], ...})
        if len(out) >= topk:
            break
    return out
```

조각을 나눌 때 **발화 구간 경계를 살리고 앞뒤를 겹치게** 했다. 고정 길이로 자르면 문장 중간이 끊겨 검색 품질이 떨어진다. 답변에는 몇 분 몇 초 구간인지(`pos`)를 함께 돌려줘서, 사용자가 원본 녹음에서 바로 확인할 수 있게 했다.

## 5. 만세력 엔진 — 역사적 표준시 보정

`05_saju-service` · Python

사주 계산은 태어난 **시각**이 기준이라 시간대 처리가 결과를 바꾼다. 한국은 표준시 자오선이 여러 번 바뀌었고 서머타임도 있었는데, 이걸 무시하면 시주(時柱)가 통째로 틀린다.

```python
def standard_meridian(date):
    """해당 날짜의 한국 표준시 기준 자오선 (표준시 변경 이력 반영)"""
    if date < datetime.date(1908, 4, 1):  return 127.5   # 표준시 도입 전 — 한성 지방시 근사
    if date < datetime.date(1912, 1, 1):  return 127.5   # 대한제국 표준시 UTC+8:30
    if date < datetime.date(1954, 3, 21): return 135.0   # UTC+9
    if date < datetime.date(1961, 8, 10): return 127.5   # UTC+8:30
    return 135.0                                          # 현행 KST


def true_solar(dt, longitude=SEOUL_LON):
    """시계시 → 진태양시. 서머타임 해제 후 자오선 차를 보정한다."""
    dst = any(s <= dt < e for s, e in DST_PERIODS)
    if dst:
        dt -= datetime.timedelta(hours=1)
    mer = standard_meridian(dt.date())
    off = (longitude - mer) * 4.0        # 경도 1도 = 4분
    return dt + datetime.timedelta(minutes=off), dst, mer, off
```

## 6. eGovFrame 환류관리 — 설계 의도를 코드에 남기기

`03_survey-platform-egovframe` · Java 17 + Spring/eGovFrame

조사 결과가 보고서로 끝나지 않고 개선 과제로 이어지도록 PDCA 순환을 시스템에 넣었다. 설계 의도와 제약을 주석으로 남겨, 나중에 보는 사람이 왜 이런 제한이 있는지 알 수 있게 했다.

```java
/**
 * 환류 개선과제 (설계_02 PDCA): IPA 중점개선 → 과제 등록 → 개선계획(Plan) → 실행(Do)
 * → 차년도 이행점검(Check) → 달성/이월(Act, 연도 연계).
 * "보고서에서 끝나던 IPA가 시스템에서 순환된다" — 발표 데모 핵심.
 * 모든 상태변경 POST는 세션 CSRF 토큰(_csrf)을 검증한다.
 */
@Controller
public class FeedbackController {

    /** FB_PLAN.*_TX / FB_RESULT.RESULT_TX = VARCHAR2(2000 CHAR)지만
        물리 4000바이트 한도(한글 3바이트)로 1000자 제한 */
    private static final int TEXT_MAX = 1000;
```

Oracle의 `VARCHAR2(2000 CHAR)`는 문자 수 기준이지만 물리적으로는 4000바이트를 넘을 수 없다. 한글이 3바이트이므로 2000자를 채우면 6000바이트가 되어 들어가지 않는다. 그래서 입력 단에서 1000자로 막았다.
