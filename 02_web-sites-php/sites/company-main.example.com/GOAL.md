# [회사명] 주식회사 웹사이트 재제작

## 목표
WordPress에서 순수 PHP 8.1 + Apache + MySQL MVC 패턴으로 웹사이트 전면 재제작

## 기술 스택
- PHP 8.1 (순수 PHP, MVC 패턴)
- Apache 2.4 + mod_rewrite
- MySQL 8 / MariaDB (PDO)
- PHPMailer (이메일)
- TinyMCE 6 (리치 에디터)
- Tailwind CSS CDN + Vanilla JS
